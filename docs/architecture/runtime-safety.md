# 1. 运行安全

**位置：** [架构总览](overview.md) → [观看时序](flows/viewing.md) → 运行安全。**关注节点：** 缓存读取、版本失效和晚到响应；**失败去向：** 舍弃不可靠提示，英文继续显示。

本页约束[观看流程](flows.md)的数据复用、失效与信任边界；不授权账号、个人档案或跨设备同步。

## 1.1. 缓存与事实

| 层 | 可保存内容 | 失效依据 |
|---|---|---|
| 扩展 L1 | 本机当前字幕可用的提示。 | 字幕/视频切换、观察序号、资料版本与时效。 |
| Redis | 已发布共享资料及具备可靠来源身份的派生副本。 | 资料与规则版本、内容修订、撤回与硬性过期。 |
| PostgreSQL | 按公开合同维护的词库事实与发布版本。 | 资料负责人的保留、删除及发布合同。 |

缓存可重建，不绕过已发布状态。原始字幕、观看地址、模型载荷或凭据不得进入共享缓存键、日志键或指标标签。本机观察序号不能替代可靠来源修订；无法证明共享复用安全时只使用本机结果或不缓存。

## 1.2. 失效与降级

- 资料、规则、来源修订或当前字幕变化时，旧提示必须未命中或被拒绝。
- 缓存未命中只允许查询已有资料，不启动模型生成或当前字幕的后台补全。
- 后端和缓存不可用时英文继续显示；不得用失效答案维持覆盖率。
- 第三阶段分析失败时保持已发布资料；撤回或回退后缓存必须按发布版本失效。

## 1.3. 信任与授权

来源适配器负责输入归一和有界上下文，API 校验语言、大小、范围与关联身份；Enrichment 校验资料适用性及提示资格。页面、字幕和离线模型输出都只是数据，不得成为执行指令。

跨模块只经公开合同访问数据。第三阶段模型材料应在发布前校验，不得以直接写缓存或词库表绕过审核。新增反馈采集、持久化、模型外发及保留删除策略需要独立确认；观看请求不是这种授权。

## 1.4. 观测与验证

日志仅记录受控步骤、计数、状态、版本与耗时，不记录原文、观看 URL、中文提示、密钥或模型载荷。观看性能与离线分析成本分别核算，不以个人身份作为观测维度。

检查覆盖缺失资料、冷缓存、超时、字幕切换、迟到响应、版本更新与回退；第三阶段另验证模型异常和未审核结果隔离。未执行的检查不能称 PASS，具体证据只在[状态页](../roadmap/master-plan/status.md)维护。
