# 1. 字幕提示与事后改进流程

本页细化[路线图核心原则](../roadmap/master-plan.md#11-核心原则)。观看链路与事后分析之间只有已发布资料的读取关系；不存在当前字幕触发模型、等待任务或接收模型补全的分支。

## 1.1. 观看流程

| 步骤 | 处理 | 终止与失败边界 |
|---|---|---|
| 接收字幕 | 来源适配器产生有界 `CaptionContext`；英文立即显示。 | 无可靠字幕时不伪造输入。 |
| 读取资料 | 匹配有效本机结果，或通过服务端查询已发布词库和语义资料。 | 缺失或不可用时不调用模型填补。 |
| 规则决策 | 定位词段、筛选价值与密度，判断已有证据是否足以形成可靠短释义。 | 词库命中不等于语境正确；不可靠则不提示。 |
| 返回结果 | 返回绑定原文、词段范围及资料版本的提示或空结果。 | 不承诺 `pending` 模型工作，不创建补全任务。 |
| 本机展示 | 复核当前视频、字幕、观察序号和时效，再应用本机抑制偏好。 | 字幕变化、seek、导航或晚到时丢弃旧结果。 |

网络查询已有资料可以异步返回，但“异步”不意味着允许生成新语义或调用模型。缓存未命中、网络超时和服务故障均退化为已有可靠提示或仅英文。

## 1.2. 事后分析流程

此流程只属于[第三阶段](../roadmap/master-plan/improvement.md)，独立于观看请求：

1. 在明确数据授权与保留边界后，组织缺失词库材料和反馈。
2. 离线分析缺口；如使用模型，其输出仅作为待校验资料，不直接进入词库查询结果。
3. 评估、审核并发布资料版本；不合格或失败时保留已发布版本。
4. 后续观看请求读取已发布资料。错误发布应可撤回或回退，不向当前字幕推送补全。

本页不规定采集接口、自动调度或任务存储结构，也不授权从字幕请求或日志反向构造分析数据。

## 1.3. 效率优化边界

[第二阶段](../roadmap/master-plan/performance.md)只优化已有资料的查询、批量准备和复用；不依赖第三阶段在线运行。缓存和资料版本匹配由[运行安全](runtime-safety.md)约束。

## 1.4. 相邻合同

[模块边界](boundaries.md)定义调用责任；[来源合同](source-contract.md)与[字幕合同](caption-contract.md)定义输入和失效；[语义资料合同](semantic-contract.md)定义可靠资料的使用与发布边界。
