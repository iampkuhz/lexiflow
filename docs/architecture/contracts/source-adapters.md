# 来源适配合同

> Proposed。先读 [横切合同导读](README.md)。

让来源差异停在适配器，核心只接收稳定身份和规范片段。

## 精确语义与后续证据

下面保留原合同的任务映射、必须/应当/后续条件、符合性、验收和未决假设。它们约束后续实现，不能从文档存在推断产品通过。

<!-- retained-contract:start -->
**对应任务：`LF-TSK-ADP-0001`**

来源适配器负责从具体来源获取并规范化内容。内容接收来源无关的规范表示；词库、个人词汇、学习归约、语义和提示编排不得依赖 YouTube DOM、网页选择器、PDF 库、音频解码器或平台 SDK 类型。

<a id="71-canonical-port-semantics"></a>

### 7.1 规范端口语义

端口在概念上交付以下语义；这些是合同值，不是实现方法签名：

| 语义 | 必须不变量 |
|---|---|
| 来源身份 | 同一来源对象在适配器可观察生命周期内稳定、不可由展示标题代替；来源种类只是元数据，不允许核心据此分支平台逻辑。 |
| 来源修订号 | 内容变化时可比较；无法得到原生修订号时由适配器产生保守指纹，并明确可靠度。 |
| 片段身份 | 在来源修订号内稳定；重复采集同一片段得到同一身份，内容变化或边界重切有新修订号/身份。 |
| 文本单元 | 保留原始语言、规范化文本、可选说话人/轨道信息与提取来源证明；不得伪造缺失转写。 |
| 来源位置 | 表达时间范围、页/区域、文档顺序或选区中的可用部分；核心只消费通用位置能力，不解析平台私有定位。 |
| 上下文窗口 | 当前片段必需；上一个/下一个可缺失、迟到、乱序或不连续，并显式说明完整性。 |
| 播放/阅读状态 | 可选位置、速度、暂停/跳转或选区状态；只作为上下文/行为输入，不改变内容身份。 |
| 适配器能力 | 明确是否实时、带时间轴、可跳转、有序、可选择、转写完整；缺少能力是合法状态。 |
| 来源证明 | 标明适配器/来源种类、合同版本、采集时间、语言/轨道与规范化版本；不携带页面凭据。 |

**必须**

- 适配器对同一输入确定性地产生规范身份、修订号和规范化；结果顺序、重试和重复回调不改变身份。
- 当前片段可独立交付。上一个/下一个、时间、说话人、完整转写或语言置信缺失时，不阻塞英文优先，也不以空字符串冒充已知。
- 来源专有的元数据留在由适配器拥有的不透明参考；核心领域不能导入、解析或条件判断它。
- 适配器不决定用户是否需要提示，不读取个人词汇档案，不调用具体语义供应商，也不产生学习归约熟悉度。
- 页面/文档/音频内容按不可信数据规范化，限制大小与窗口；隐藏脚本、控制指令和富标记不能越过端口成为执行语义。
- 来源修订号或片段绑定不能证明时，结果使用保守的新身份/修订号，使旧提示注释未命中，而不是冒险复用。
- 无字幕/转写时明确报告内容不可用/能力缺失；不得猜测文本。

**应当**

- 支持增量片段和补录，使实时来源不必等待完整转写。
- 将重叠、断句变化和跳转后乱序归一成可测试事件，允许内容/扩展做去重和陈旧拒绝。
- 可访问性文本、官方字幕或用户明确选区优先于不可解释的页面抓取；来源证明保留来源质量等级。

**后续条件**

- 阶段 5 实现 YouTube 扩展适配器；网页、PDF 与音频/播客适配器只在 ADP 后续研究任务证明产品价值后激活。
- 具体抓取 API、DOM 选择器、PDF 解析器、ASR 方案和平台权限均由各适配器阶段决定，不进入核心合同。

<a id="72-conformance-examples"></a>

### 7.2 符合性示例

| 测试样例 | 适配器输入能力 | 规范输出期望 | 缺失/变化处理 |
|---|---|---|---|
| YouTube 录制视频 | 带时间轴字幕轨道、播放器位置、视频身份；字幕回调可能重复或重切。 | 当前带时间轴片段、稳定来源/修订号/片段、可选上一个/下一个、`live=false`、`timed=true`。 | 无下一个时显式不完整；跳转/轨道/修订号变化使旧结果陈旧；DOM/轨道私有对象不越界。 |
| YouTube 实时 | 逐步出现的带时间轴字幕、窗口持续滚动。 | 增量当前片段、单调可比较的适配器修订号/来源证明、有限上下文窗口、`live=true`。 | 文本修订产生可比较修订号；不等待直播结束；迟到增量不覆盖当前片段。 |
| 网页文章/选择 | 文档身份、阅读顺序、段落或用户选区，无可靠播放时间。 | 有序文本片段、文档/选择位置、当前 + 可选相邻块、`timed=false`、`selectable=true`。 | DOM 重排但文本/身份等价时保持规范；内容实质变化更新修订号；脚本/导航噪声不作为文本。 |
| PDF 页面/选择 | 文档指纹、页面/顺序、选区或提取文本，可能多栏/扫描。 | 页面/顺序位置、规范化文本片段、提取来源证明、可选相邻段。 | 无文本层时报告能力缺失或待外部转写；不制造阅读顺序；新 PDF 修订号不复用旧上下文。 |
| 音频/播客转写 | 节目身份、带时间轴转写/ASR 片段、播放位置。 | 带时间轴片段、转写来源证明/质量、有限前后文、`timed=true`、`seekable` 按来源声明。 | 无转写时内容不可用；ASR 修订更新修订号；低置信文本被标记而非当作确定字幕。 |

这些测试样例只证明同一端口能承载来源差异，不承诺阶段 1 实现未来来源。

<a id="73-cross-source-conformance-suite"></a>

### 7.3 跨来源符合性测试集

**必须**

- 每种测试样例通过同一组规范合同断言：身份稳定、修订号可比较、当前必需、邻居可选、位置能力可缺、语言/来源证明明确、大小有界。
- 测试集覆盖重复、乱序、缺上一个/下一个、片段重叠、跳转、来源修订号、未知语言、无转写和超长输入。
- 核心测试样例只使用规范值；任何断言若需要 YouTube 视频对象、DOM node、CSS 选择器、PDF 页面类或音频解码器类型，即判为适配器泄漏。
- 同一规范内容上下文进入提示编排/学习归约时，不因来源名称改变提示需求、个人档案负责人或事件语义。
- 符合性测试样例使用合成文本和身份，不含真实用户字幕、观看历史或受版权限制的完整材料。

**应当**

- 合同测试集由所有来源适配器复用，适配器可添加自己的获取测试，但不能删除共享断言。
- 建立来源无关标准样例上下文窗口，证明带时间轴与无时间轴来源都能触发相同的快速/慢速提示编排合同。

**后续条件**

- `LF-TSK-ADP-0002` 在阶段 5 用依赖/导入 gate 证明核心无 YouTube 类型；后续适配器研究各自提交符合性收据。

<a id="74-acceptance-evidence"></a>

### 7.4 验收证据

`LF-TSK-ADP-0001` 的 `PASS` 证据至少包括：

1. 一份来源无关端口审查，覆盖身份、修订号、片段、位置能力、上下文完整性、语言与来源证明，且无平台 SDK/DOM 类型。
2. YouTube 录制/实时、网页、PDF 与音频五类合成测试样例的期望结果，证明带时间轴与无时间轴、完整与部分上下文均可表达。
3. 确定性/性质证据，证明重复/乱序输入可去重，来源修订号或实质内容变化不会误命中旧提示注释。
4. 禁止依赖证据，证明内容以外的核心领域不按来源种类分支，也不依赖 Chrome、YouTube、网页、PDF 或音频实现类型。
5. 无文本旅程，证明字幕/转写不可用时系统明确降级且不猜测内容，英文 first/原来源体验继续。

### 7.5 未决假设

| ID | 假设 | 验证时机/负责人 |
|---|---|---|
| ADP-A1 | `identity + revision + segment + optional location` 足以统一带时间轴与无时间轴来源。 | 阶段 5 YouTube 实现和后续网页/PDF 探索验证。 |
| ADP-A2 | 三段式有界上下文是初期质量/隐私/成本的合理折中。 | 阶段 4 语义评估。 |
| ADP-A3 | YouTube 字幕回调可构造稳定片段身份，即使平台重切断句。 | 阶段 5 扩展探索验证；失败则使用保守修订号而非放宽陈旧检查。 |
| ADP-A4 | 网页/PDF/音频只需来源专有的获取，核心学习归约/提示编排语义无需分叉。 | 每个未来适配器的符合性审查。 |
