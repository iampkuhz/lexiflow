# 1. 语义资料使用与发布合同

**位置：** [架构总览](overview.md) → [两条流程](flows.md) → 语义资料。**观看上游：** 已发布资料与词库版本；**下一步：** Enrichment 判断适用性。**事后失败：** 未审核或发布失败的材料保持不可见。

语义资料说明词段在特定适用条件下的含义，不等同于模型的即时回答。观看与事后分析的流程见[字幕提示流程](flows.md)，阶段授权见[产品路线图](../roadmap/master-plan.md)。

## 1.1. 观看时的使用边界

Enrichment 只通过公开合同消费已经发布、版本匹配且适用条件成立的词库和语义资料。规则负责定位词段、选择可用证据并决定是否提示；证据不足时放弃提示。

- 禁止同步模型调用、当前字幕后台模型补全和模型预取。
- 缓存未命中、多义歧义或资料过期不构成模型调用理由。
- 多义列表、截断词典文章、未经消歧的首义、供应商自评置信度都不能直接充当可靠语境答案。
- 响应须绑定当前原文、范围和资料版本；当前字幕失效即放弃结果，不跨句展示。

## 1.2. 事后语义补充

第三阶段可在独立的缺失分析中通过供应商无关的能力生成语义材料。具体模型和提示词由基础设施适配器隔离，领域不依赖供应商 SDK。

模型成功不等于资料可发布。资料需经过来源与适用条件核对、质量评估、审核和版本发布后才能供后续观看使用。发布失败、模型不可用或离线任务停止时，继续使用已发布资料。不得将未审核结果写入观看缓存绕过发布。

## 1.3. 所有权与接口边界

Lexicon 拥有可复用词库知识和版本；Enrichment 拥有当前字幕的规则决策与派生提示。离线产物只能经资料负责人的公开发布合同成为知识，不能跨域写表。

本次不新增供应商 API、数据结构、任务队列或发布接口；第三阶段展开时再定义最小分析和发布合同，不保留当前字幕语义任务作为观看接口。

## 1.4. 隐私与验证

新增分析材料的取得、发送、保留与删除必须先明确授权；不得默认把真实字幕、观看地址、行为、个人偏好或供应商原始载荷纳入分析和日志。

验收应分别证明：观看没有模型调用、缺少可靠资料时安全放弃、离线输出未经审核不可见、发布版本可核对及回退。实际代码与证据以[状态页](../roadmap/master-plan/status.md)为准，不从文档推断实现已完成。
