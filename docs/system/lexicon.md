# 1. 共享词库合同

[架构总览](../system.md) → [观看流程](flows.md) → 共享词库合同。本文定义 Lexicon 的导入、查询与发布边界。

Lexicon 保存可跨内容复用的英文词汇事实；不保存某次字幕采用哪个义项、用户行为或供应商载荷。准备资料、查询投影和约束见[词库持久化模型](lexicon/data-model.md)。

## 1.1. 规范主词条与查询形式

规范 `lemma` 是来源无关的词条业务键；`entry_id` 是由它派生的正 63 位稳定身份（SQLite INTEGER，接口使用十进制字符串）。每个原形、别名、屈折形在逻辑 lookup 有一条准确形式映射。单词和固定短语都可作为主词条；一条屈折形式可以自然地对应多个主词条，不能任取第一条。`LexiconEntry` 负责离线准备阶段的词形与冲突校验；观看阶段只接收 `LexiconHintCandidate`，包含匹配词形、词条身份、资料版本、最终决定、优先级及可空的词频名次；仅 HINT 给出义项身份和短释。别名的义项身份仍按规范词形派生。

一个已发布资料版本由 `lexicon_dataset.lexicon_version` 表示。Annotation 同时引用词条、义项与资料版本；旧身份不被新资料原地改写。完整重导后查询缓存按版本清空；本机偏好独立存储，并按规范 lemma 稳定身份关联，不因词库版本变化丢失或串绑。

## 1.2. 导入期证据到最终决定

原始 BNC 正整数作为 `bnc_rank`，仅用于常见词档位和词库查询的来源排名；缺失或无效为空。不把 FRQ、展示名次或优先级用于 Top N 档位。对有原始 BNC 排名且其他条件合格的普通单词，用户档位 Top N（默认 1500，可选 1000/1500/2000）用于本机过滤；没有 BNC 排名的单词沿用导入期 Oxford 基础词规则。固定功能词与完整短语规则独立。

当前视频显示独立的发布名次 `frequency_rank`。离线以每个规范单词 BNC／FRQ 有效正名次的最小值升序排列，并列按规范 lemma 的二进制顺序打破，从 1 连续编号。变形与别名共享名次，缺数据的单词和短语不显示名次。获得名次不表示该词必定会提示。导入期的 Zipf 和复杂标签确定提示／预热的 `priority`，展示名次不参与选词、预热或观看行为推断。

可查询但无合法默认释义、功能词或低信息短语保留为 BLOCK，以维持同形歧义边界；默认首先采用离线核对的来源记录，首项无效不扫描后项补位。正常观看只读已发布短释，不实时消歧，不补查来源。
## 1.3. 观看期确定性查询

观看请求仅因同组、同视觉行的连续新增片段到来而枚举一至三个词的准确形式；可带入同视觉行紧邻的至多两个、合计不超过 48 个 UTF-16 单元的旧尾片段以补全跨边界词组，但提示必须延伸到新增片段，不能单独补译旧内容；四词及以上不枚举。一个含 10 个不同 token 的句子最多生成 `10+9+8=27` 个形式，去重后缓存未命中的形式合并为**一次** SQLite 批量查询；本次请求还会独立执行一次资料版本核对。全部形式已在 L1 时批量词形查询为零次，版本核对仍为一次。通过一次批量 SQL 关联 `lexicon_form` 与 `lexicon_entry`，不逐词查库，也不请求模型。命中多个词条时保留全部候选，Enrichment 检查词边界、UTF-16 区间、歧义、低信息短语、重叠；不设置固定三条提示上限。BLOCK 只拦截自身准确形式，不因单词被阻断就阻断包含它的完整短语。

API 查询版本与词形是两类读取；版本变化清空可重建缓存。L1 正向与负向预热分别有界；未命中不创建持久化事实或 pending 工作。

## 1.4. 来源、许可与发布

完整来源清单记录来源标识、许可、文件 SHA-256 和取得时间；原始文件按摘要受控保留供离线回查。不提供“每个词在每个来源的原始释义逐条数据库查询”。发布前完整扫描格式、计数与 canonical 冲突；写入在一个事务内完成，失败回滚，不保留数据库中间状态。操作入口和公式见[离线词库导入](../scenarios/lexicon-import.md)。

有界术语的独立事实、许可、内容审核发布与确定性包含竞争见[有界术语来源](lexicon/reviewed-phrases.md)。
