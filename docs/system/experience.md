# 1. LexiFlow 产品说明

**位置：** [文档首页](../README.md) → 产品说明。**下一步：** [系统总览](../system.md)说明系统如何提供体验；[产品术语](../reference/product-glossary.md)解释产品概念。路线图见[长期计划](../roadmap/master-plan.md)，交付进度只见[状态页](../roadmap/master-plan/phase2/status.md)。

LexiFlow 帮助用户在观看英文视频时保留原文、减少查词中断：它基于已发布资料，在有价值的英文词段旁提供简短中文提示。英文始终优先；资料不足或不适用时，继续只显示英文。多义词默认使用发布时确定的首义，产品不承诺逐句语境消歧。

## 1.1. 用户体验

1. 用户播放带英文字幕的 YouTube 点播视频；Chrome 扩展读取已渲染字幕，英文不等待服务端。
2. 系统根据已发布资料与确定性规则判断是否提示；提示若仍对应当前字幕，显示在英文词段旁，不翻译整句。
3. 切换字幕、seek、导航或迟到响应不能把旧提示带到新字幕；不可用时保留英文。
4. 用户可明确选择“不再提示”。该偏好仅保存在本机，并绑定词段与词库版本；不上传、不推断熟悉度。

提示形态与范围属于产品体验；行内呈现约束见[产品架构规范](../../openspec/specs/product-architecture/spec.md)。输入、资格和失效的精确合同分别见[字幕内容合同](captions.md)、[共享词库合同](lexicon.md)和[运行安全](runtime-safety.md)。

## 1.2. 产品范围与取舍

首版面向 Chrome 扩展与 YouTube 英文字幕，提示单词、短语或专业术语。提示以不打断观看为先：不显示整句双语翻译，不为增加覆盖率而牺牲可靠性；默认首义可能不适配具体语境，这是已接受的质量边界，不代表已完成消歧。

观看只读取已发布资料，**不调用、等待、预取或订阅模型工作**。第三阶段规划的独立事后资料改进可使用模型；其产物须经评估、审核和版本发布，才可供后续观看读取。观看字幕本身不授权采集、保存、外发或反馈分析。

账号、服务端个人档案、自动行为评分、跨设备同步、复习、推荐与社交不属于当前产品范围。扩展仅保存用户明确设置的本机词段抑制偏好。增加来源或能力前，须重新确认可靠文本、身份、隐私与产品范围。

## 1.3. 取舍原因与复审条件

- **英文优先、提示可为空。** 等待完整翻译会打断观看；只有真实时延、可用性或质量证据说明边界不合理时才复审，不能用即时模型补齐覆盖。
- **只保留显式本机偏好。** 用户动作能直接改善下次提示，点击或停留不能可靠推断熟悉度；账号和同步会增加身份、冲突与隐私运营。确需跨设备或服务端档案时，须先批准数据、删除／导出与威胁模型边界。
