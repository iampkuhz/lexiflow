# 1. 字幕来源、身份与输入合同

[系统总览](../system.md) → [观看流程](flows.md) → 字幕输入。Chrome 扩展把当前可见英文整理为 `CaptionIncrementalRequest`；API 不保存服务端字幕会话，词库查询见[词库合同](lexicon.md)。

## 1.1. 来源和身份留在浏览器

英文只取自 YouTube 已渲染的 `.ytp-caption-segment`。播放位置和被动取得的 JSON3 只用于核对真实轨道、窗口和时间，不下载替代字幕。未知元信息保留为 null；短时无法匹配不视为换轨。新的确认轨道、seek 或导航使旧结果失效。

扩展按组和可视行整理当前片段。只要保留片段仍可见，它的 key 不变，正文只能裁去前缀；新增后缀使用新 key。DOM 重建、换行、短时空帧或原生时间窗与显示错位不能凭空制造新身份。片段 key 不是可持久引用的内容身份，不进入共享缓存或后台任务。

## 1.2. 后端只接收提示需要的数据

`POST /api/v1/caption-hints` 请求包含：

- `currentSnapshot.captions`：按可见顺序排列的字幕组；每组 `segments` 包含 `key`、`text`、`append` 和 `line`。`append` 表示本次待处理，不是来源追加标志；同组同行才可匹配词组。
- `previousSegments`：仅发送当前仍可见的旧片段，按上次成功确认请求中的顺序保留其 `key` 与原始 `text`；无交集时为 `[]`。后端仍拒绝用同一个 key 替换正文或增长。主题、轨道、窗口和时间不进提示请求。

两个输入各限 500 个片段和 500 个 UTF-16 单元。API 输出 `processedKeys`、`lexiconVersion` 与 `hints`。处理覆盖包括没有提示的片段；没有取得资料版本时版本为 null。提示用起止片段 key 和片段内 UTF-16 半开区间定位，包含简短中文释义、十进制字符串词条 ID 和当前词库版本的 `frequencyRank`（正整数；未排名时为 null），不返回字幕原文或内部义项身份。

## 1.3. 确认、失效与降级

扩展只确认与发送快照相符的处理覆盖；失败不推进确认范围。纯换行不重新查询；滚动成旧行只保留已经显示的中文，迟到响应不补写旧行。短时空帧立即隐藏增强层但保留片段身份；超过短时窗口、隐藏或关闭增强时丢弃不再适用的结果。英文始终不等待后端，也不会触发模型。

页面和字幕是不可信数据，不作为执行指令。来源无法证明时不伪造字幕、轨道或时间。观测与持久数据边界见[运行安全](runtime-safety.md)，体验与合成验证见[Chrome 扩展本地体验与 E2E](../scenarios/extension-e2e.md)。
