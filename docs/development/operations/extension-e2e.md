# 1. Chrome 扩展双语提示体验与 E2E

> 位置：[工程地图](../overview.md) → [Operations](../operations.md) → Extension E2E。本页验证浏览器交互，不替代真实词库质量验收。

## 1.1. 可见交互与失败边界

扩展只处理 YouTube 播放页中 `video`、`.html5-video-player`、`#ytp-caption-window-container` 与
`.ytp-caption-segment` 提供的可见英文快照。隐藏字幕、广告和跳转期间不请求提示。

英文不等待网络：完整英文先在稳定增强层即时显示，再可逆裁剪原生重复绘制，不修改来源节点。中文仅在 `READY` 响应绑定同一原文、合法来源引用与发布版本后原位补入，例如 `A reliable(可靠的) result.`。保留来源可见分行，中文增加后允许自然换行；无提示和请求失败仍保留同层英文。来源失效、广告、导航或关闭增强时解除裁剪，恢复原生绘制。

MutationObserver 在绘制前检测新快照，立即取消旧请求并替换为当前英文，然后才执行异步摘要与短暂请求合并。摘要完成及结果显示时都重验当前字幕。通信失败不自动重试、不推进上次成功确认的请求快照；等待下一次有效字幕变化，再发送最新快照与上次成功快照，不积压已退出视图的内容；相同文本在 seek 后也不能复用旧提示。合并等待为 16 ms，请求硬超时为 1500 ms；两者均不阻塞英文绘制，超时结果不得延续到下一句。初始化前或无法完整重建英文时保留原生字幕。客户端不截断文章、不选择首义；后端无可靠资料返回 `NO_PENDING`，不创建模型或异步补全任务。

## 1.2. 本机构建、安装与体验

完整的依赖、API 启动、词库选择和扩展安装步骤统一在[本机体验](local-experience.md)。
API 默认供扩展访问的地址为 `http://127.0.0.1:18080`；使用完整词库前须[导入并发布](lexicon-import.md)。

若默认端口已被其他实例占用，可在同一环境中先执行 `export LEXIFLOW_API_PORT=18081`，再运行零参数的 API 启动与扩展构建命令。构建参数只允许本机端口，不能配置远端主机；
生成的 API 地址与 host permission 使用同一端口。常规测试会重新构建默认端口，实际安装前须按所选端口再次构建。

源码更新后需要重新构建 `extension/dist`、刷新扩展并刷新播放页；后端改动需重启 API。扩展只请求
当前字幕，不持久化字幕或观看历史，不向服务器上传本机抑制偏好。点击中文可抑制对应词条；
工具栏弹窗可开关当前页面增强，并在“提示偏好 · 仅本机”中确认恢复全部提示；观看画面没有常驻设置菜单。关闭增强立即恢复原生字幕并停发请求，刷新或换视频恢复开启，其他标签页不受影响。聚合诊断仍通过增强层的 `data-lexiflow-diagnostics` 属性供开发检查，不展示到日常观看界面。抑制只以词条 ID 与发布版本组合保存到 `chrome.storage.local`，最多 500 项；新版本不自动继承，不保存字幕、不使用 sync、不上传或推断熟悉度。读取失败不展示中文，写入失败不能宣称保存成功；导航后的旧弹窗操作拒绝。

## 1.3. 自动化验证

```bash
cd extension
npm ci
npx playwright install chromium
npm test
npm run e2e
```

单测验证原文绑定、区间、单义短释义、状态一致性、多个词段排序、字符边界、取消和迟到响应。
E2E 加载真实 Chromium 扩展，使用合成 YouTube 页面、独立本机 API 与内置确定性词库；不复用
用户正在运行的 API，不读取真实模型密钥或请求真实模型。测试覆盖行内位置、标点保留、原字幕未改写、
绘制前清除、来源隐藏、广告、seek、空结果、超长输入和网络降级；本机抑制在刷新后保留、恢复后重新展示，
偏好操作不调用后端。新增 popup 集成测试只将活动标签查询绑定到本地夹具，弹窗文档和跨扩展消息是真实执行；覆盖开关、在途取消、导航重置和陈旧操作拒绝。

需要连续运行和布局验收时，在同一目录显式执行：

```bash
LEXIFLOW_EXTENDED_ACCEPTANCE=1 LEXIFLOW_SOAK_SECONDS=375 npm run e2e
```

扩展验收沿用自动化脚本的临时 Chromium profile 和完全路由到本地 HTML 的夹具，不触及用户 profile 或真实网站。
以实际墙钟连续运行 375 秒，逐句检查英文即时保留、旧结果清除、最终提示与有界统计；短时参数只作诊断，不能冒充完整连续运行证据。
布局覆盖普通/窄窗口、夹具全屏、150% 文字字号、长字幕和三提示。三提示使用明确标注的 renderer 合同 mock，其余布局与连续运行调用实际内置 API。
报告及截图位于 ignored `tmp/quality/extended-acceptance/`，必须人工查看截图，不仅检查几何断言。

这些检查证明浏览器与 API 的工程链路，不证明实际词库的语境准确率或真实 YouTube 适配效果。

## 1.4. 来源合同限制

YouTube 渲染 DOM 只提供屏幕文本快照与播放器读数，没有可靠的轨道修订或真实字幕起止时间。
本机序号、观察修订与摘要只用于当前请求的去重、取消与迟到结果拒绝，不得充当持久内容修订或共享缓存键。

字幕过短或资料查询太慢会使提示被放弃；扩展不延迟英文，也不把旧中文延续到下一句。实际页面选择器、
字幕布局与全屏兼容性仍需本机体验核对，不兼容时应降级到原英文字幕。

## 1.5. 日志与排障

播放器的 `#lexiflow-caption-overlay` 元素通过 `data-lexiflow-diagnostics` 提供本机内存聚合：
采集、合并等待、传输、词库查询、规则、API、渲染和端到端耗时；包含总计数及最近 256 个样本的 p50/p95。
无样本的百分位为 null，不冒充零耗时。API 用 `Server-Timing` 返回服务端自身计时，客户端不相减跨进程时钟。
扩展 service worker 的 `[LexiFlow]` 日志仅给出结果和请求耗时。诊断应区分资料缺失、查询耗时与结果格式错误，不把在线模型配置作为观看的前提。配置参数与常用排障入口见[排障导航](../troubleshooting.md)。

`cancelled-acquisition`、`cancelled-before-request`、`cancelled-in-flight` 区分失效位置；`late-ready` 表示已返回提示但过期丢弃，`stale-at-render` 表示最终显示校验拒绝。取消可能来自换句、跳转、关闭等，不能全算成延迟漏译。`missing-server-timing` 记录成功响应缺少服务端完整计时；不同阶段样本数可能不同，不能直接相减其均值或百分位。

扩展日志不包含字幕原文、视频 URL、模型输入输出或密钥，不开启 HTTP 请求体调试日志；本机 API 另按用户授权把每个已处理新增片段记入独立分析文件，见[本机体验](local-experience.md)。`timeout` 与主动取消的 `aborted` 分开；`NO_PENDING` 是无可靠提示而非成功翻译。

## 1.6. 真实观看验收

自动化闭环、已发布词库抽样、renderer mock 与真实 YouTube 的证据范围分别记录，不能相互替代。自动化连续运行仍需至少 375 秒实际墙钟；用户将扩展安装到 default profile 后，在指定真实英文视频检查完整播放。

至少人工核对十个实际提示；不足十个则全部核对并明确覆盖不足。核对已发布默认第一候选、词条/义项/版本、准确 UTF-16 区间和缺资料放弃，不用硬编码目标视频或截取未发布词典制造成功。默认首义或字面义与语境不适配单独统计，不冒充语义准确率，也不豁免来源、默认义一致性与版本检查。同一词条不同出现位置可分别提示，完整重复提示去重，以当前提示合同为准。

普通播放器、全屏和缩放均检查 DOM 与最终截图：英文完整、中文紧随词段、无叠字遮挡或上一句残留、原生控件可用。记录提示次数、覆盖率、成功/无提示/失败/取消分布和分段时延，明确样本及分母；不能用成功请求掩盖失败。截图和字幕只存本机 ignored 验收产物，不提交或外发。

子功能还必须覆盖歧义/坏资料拒绝、大小写/别名/词形/标点/Unicode、重复与重叠及乱序确定性、真实 PostgreSQL、字幕换句/跳转/导航/广告/暂停恢复/关闭、取消迟到、偏好恢复与页面开关；关闭后无请求和旧结果复活，不影响其他标签页。当前跨模块定位见[验收矩阵](../../roadmap/master-plan/phase2/acceptance.md)。必需项未跑为 BLOCKED、断言失败为 FAIL；独立审查只消费冻结 diff/evidence，不重跑交付命令。正式交付按 Harness 当前风险计划取得独立验收，不能以文档或能启动替代。
