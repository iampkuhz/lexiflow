# 1. 校验记录模板

> 上级：[Reference](../reference.md)。用于说明事实，不签发正式 receipt；执行步骤见[门禁场景](../scenarios/run-repository-gates.md)。

```markdown
# 1. 校验记录

## 1.1. 输入
- Task／变更与实际修改范围：
- 冻结输入或报告绑定范围：
- 实际执行者及身份来源（不得自造）：

## 1.2. 已执行检查
- 入口文件与完整命令：
- 实际结果：PASS | BLOCKED | FAIL
- 实际耗时／环境；与规划预算分开：
- 原始报告／日志／适用 receipt 定位：

## 1.3. 结论边界
- 本次证明：
- 必需但未运行的检查／阻断原因：
- 未证明内容与下一步：
```

只填写真实输入和实际产物；没有 receipt 就注明未取得，不用手写模板替代 [Delivery Gate](../change-delivery/delivery-gate.md) 的正式记录。
