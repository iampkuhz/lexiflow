# 1. 产品路线图

**以英文字幕为主，在不影响观看的前提下，提供可靠、及时的词段中文提示。** 产品范围见[产品说明](../product/product-brief.md)。

## 1.1. 核心原则

- 观看链路只消费已发布的词库、规则和语义资料，**永不调用大模型**，包括同步、当前字幕后台补全和模型预取。
- 英文显示不等待后端；没有可靠释义就不提示，不以词典首义冒充语境答案。
- 模型仅可进入第三阶段独立的事后分析；结果经校验、发布后供后续观看使用，不回补当前字幕。
- 每阶段独立可用，后续能力可关闭、可回退，不成为基础体验的必经依赖。
- 不因路线图自动授权行为采集、字幕上传、个人画像或模型数据发送。

## 1.2. 三个阶段

| 阶段入口 | 一句话成果 |
|---|---|
| [第一阶段：基础体验](master-plan/foundation.md) | 词库驱动的端到端提示可用、及时、架构正确。 |
| [第二阶段：性能与效率](master-plan/performance.md) | 查询更快、服务更稳定、重复处理更少。 |
| [第三阶段：事后改进](master-plan/improvement.md) | 缺失分析和反馈经受控更新持续改善词库质量。 |

## 1.3. 如何逐层协作

总入口 → 阶段入口 → 阶段内功能与设计文档集。你重点确认顶层方向、阶段边界和大功能；我负责细节设计、实现与验证。每次先说明讨论层级和决策点；下级需要突破上级原则时先回到上级对齐。

只维护一套有效结论；方向确认不等于功能验收。已对齐事项、待决事项、实现差距与证据只看[状态与下一步](master-plan/status.md)。
