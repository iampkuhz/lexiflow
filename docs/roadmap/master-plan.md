# 1. 产品路线图

**以英文字幕为主，在不影响观看的前提下，提供可靠、及时的词段中文提示。** 产品范围见[产品说明](../product/product-brief.md)。

## 1.1. 核心原则

- 观看链路只消费已发布的词库、规则和语义资料，**永不调用大模型**，包括同步、当前字幕后台补全和模型预取。
- 英文显示不等待后端；一期多义词使用已按候选顺序确定并校验发布的默认首义，不因多义拒绝，也不冒充已完成语境消歧；缺少合法已发布默认译法时不提示。
- 模型产品能力仅可用于另行批准的独立事后分析；结果经校验、发布后供后续观看使用，不回补当前字幕。后续阶段待办池不是模型接入授权。
- 每阶段独立可用，后续能力可关闭、可回退，不成为基础体验的必经依赖。
- 不因路线图自动授权行为采集、字幕上传、个人画像或模型数据发送。

第二阶段正式开发须等待用户通知第一阶段全部收尾，再从核对后的最新主干建立 `phase2`。先做准备，不因任务已建立而开始实现。待办专题的排列不表示固定的第三、第四阶段。

## 1.3. 如何逐层协作

总入口 → 阶段入口 → 阶段内功能与设计文档集。你重点确认顶层方向、阶段边界和大功能；我负责细节设计、实现与验证。每次先说明讨论层级和决策点；下级需要突破上级原则时先回到上级对齐。

只维护一套有效结论；方向确认不等于功能验收。第一阶段的实现差距与证据见[状态与下一步](master-plan/status.md)，第二阶段准备、启动与执行证据见[第二阶段状态页](master-plan/phase2/status.md)。
