# 1. 后续待办专题：查询、资料与消歧试验

遵循[总路线图](../master-plan.md#11-核心原则)。本页属于[后续待办池](future.md)，汇总尚待抽取的查询、资料和消歧试验要求，不代表一个已批准的执行阶段。第二阶段处理主线与功能分层见[阶段入口](phase2.md)。

## 1.1. 目标与主要功能

- 依据当前实测瓶颈优化查询、索引、缓存命中与结果复用。
- 对已发布资料进行批量查询或提前准备，减少观看时的重复工作。
- 保持版本一致性、过期失效、资源预算和故障回退，比较优化收益与成本。

## 1.2. 输入、输出与非目标

输入为基础体验的性能证据和已发布资料；输出为语义与质量边界不变的查询、服务能力及收益证据。

提前准备只处理已有资料，不生成新语义，不以预取、缓存未命中或后台任务为由调用模型。第 1.6 节的本地词义消歧试验独立于观看链路，仅形成评估证据，不作为现有模型禁用边界的例外。不建设反馈学习，不以新增个人行为采集获得性能数据，不进行无瓶颈证据的大规模架构扩张。

## 1.3. 独立交付条件

- 相同样本、资料和规则下，优化效果可比较，不以降低提示可靠性换取速度。
- 缓存失效、资源不足或优化关闭时回退至基础观看能力，不能依赖事后分析恢复。
- 优化可独立启停或回退；基础体验的失败与隐私边界不变。

## 1.4. 候选查询优化任务

- 建立当前连续 1～3 词穷举的基线：记录 token 数、生成及去重后的片段数、缓存未命中数、实际词库命中数、SQL 往返数与耗时；只保留聚合计数和耗时，不把原字幕写入共享指标。
- 从已发布词组形式构建可重建的前缀查找结构；仅沿真实词组前缀继续扩展，以支持四词及以上的可靠短语，不恢复“对所有较长片段穷举并查库”。单词与实际命中的词组仍批量读取，不能漏掉别名、屈折形、重叠或歧义候选。
- 根据经验证的词组样例再定义 suffix 辅助匹配的语义与索引，不把任意相同尾部误当同一个词组；测量正向／负向预热比例、缓存淘汰与逐请求版本检查的代价。
- 在相同词库和字幕样本上对照基线：原有提示及空结果保持一致，新增长短语只按明确证据展示；同时核对查询键数、构建成本、内存占用、缓存失效、SQL 往返数和 p50/p95 时延。收益不足时不引入额外常驻结构。

## 1.5. 离线词库发布效率待办

- 以完整来源约 7 分钟的发布耗时为基线，分别记录基础词选择、预检、摘要核对、词条与词形写入、事务提交的耗时和计数；只保留聚合性能数据，不记录来源内容。
- 根据分段证据优化高耗时环节，并在相同来源、数据库条件下复测总耗时及各阶段耗时；保留完整预检、来源一致性核对、单事务原子发布、失败回滚和旧资料可查的边界，不以取消校验或降低约束换取速度。

## 1.6. 本地轻量词义消歧试验待办

- 面向单词和短语的上下文歧义，不做整句翻译。预先准备并审核合法义项、英文解释及固定中文短释；规则先缩小范围，仅在仍有歧义时由本地小模型选择 `sense_id`，不现场生成中文，不默认采用词典首义。
- 以运行速度快、本机资源消耗低为首要优化目标；预测准确率约 80%～90%也可接受，不以追求更高准确率为由默认采用更大、更慢或更耗资源的模型。该范围是试验可接受的质量取舍，不是已测结果；具体最低门槛与时延、内存、CPU 预算在固定评测集和目标设备上共同确认。
- 优先试验候选释义向量离线预计算、运行时仅编码目标词上下文并对合法候选评分的轻量 WSD 路线。输入包含目标词段的准确区间和有界上下文；短语识别与词义选择分别评估，先覆盖连续短语，不把单词消歧效果等同于可分离短语能力。
- 准备阶段允许 AI 辅助整理、标注、训练、模型下载和转换，经校验后冻结词库、模型及分词器。实际预测仅执行本地固定模型和确定性选择规则，不调用在线 AI、Agent 或生成式翻译服务；核对代码、权重及词库各自许可，不让真实字幕或模型载荷进入共享产物。
- 比较规则基线与轻量模型的收益，记录冷启动、预计算成本、单次及批量预测 p50/p95 时延、峰值与常驻内存、CPU 占用及模型体积。固定输入、权重和执行配置，验证重复运行的一致性；不把计算可复现当作语义必然正确。
- 在独立人工核对的评测集上分别报告单词／短语、常见／稀有义项的准确率，并同时报告拒绝率、覆盖率和实际展示释义的准确率，避免仅靠大量拒绝抬高指标。候选全部不适用、上下文不足或分数接近时允许不提示；单一候选也不自动代表语境适用。
- 试验不接入当前观看请求，不新增字幕采集授权，不下载即启用模型。若证据支持实际采用，先通过 OpenSpec 明确修订观看链路的本地模型边界、资源预算与质量取舍，再另行实现；英文展示仍不等待预测，超时或资源不足时保留英文。

## 1.7. 词义资料整理与长期管理

- 语义归并、默认候选重排、词性/领域/语体/实体标注以及结构化词义资产管理统一纳入后续待办池，不成为默认首候选展示的前置条件。
- 设计完整词条与义项底稿、来源和审核依据，按需要导出义项审核 CSV 与默认翻译 CSV；文件格式须经过具体设计，不因讨论示例直接冻结 schema。
- 保留已有完整来源及本地候选成果，明确持久保存、备份恢复与发布边界；不把模型载荷或本地运行数据提交代码仓库。
- 补充英文定义、搭配和经过核对的例句，为本地消歧试验提供候选依据；不得为填满字段而臆造标签，经验排序不冒充实测词义概率。
- 本专题不直接授权新的模型产品运行链路；已有离线整理试验依其独立范围执行，接入产品仍遵守模型、隐私和资料发布合同。
