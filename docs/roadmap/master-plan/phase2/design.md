# 1. 设计输入与冻结要求

本页保留第二阶段必须先冻结的产品决定、职责边界和可验收断言；运行时行为、字段、数据库结构与模块依赖以相应系统合同为准，不在路线图复制实现参数。当前实现状态只见[状态页](status.md)。

## 1.1. 分类、提示资格与预热资格

分类不读取个人观看、掌握度或偏好。基础词、重点、长尾、低频和未知频率是资料分类，不是个人熟练度；低频或缺失排名本身不阻断提示。基础词与完整短语分别判断，来源证据缺失不推造；提示资格、排序和正／负缓存预热资格相互独立。

默认释义遵循受控来源顺序。无合法默认释义时不提示，不以候选后项静默补位；同形不同词条保留冲突证据。完整短语的人工核对豁免必须绑定完整词条及可信来源，不由自动清洗、普通来源释义或用户输入产生，也不能越过来源身份、查询长度、释义合法性等硬校验。具体准备规则见[共享词库合同](../../../architecture/lexicon-contract.md)；持久化结果见[词库模型](../../../architecture/data-model.md)。

## 1.2. 预处理、启动与观看边界

离线资料经来源/身份校验、确定性准备、完整性核对及原子发布后，才可供后续观看读取。启动校验已发布资料和依赖；显式 demo 与正式模式隔离，缺资料、结构或依赖不合格时拒绝提示服务但不阻塞英文。

观看仅按公开词库合同读取已发布资料，结果绑定资料版本及当前字幕范围。英文先显示；缓存只复用同版本事实，不创建待模型补全任务。当前字幕采用已发布的默认首义，不宣称完成语境消歧；本阶段不引入模型、前文上下文选义、四词以上新识别算法或分析队列。具体观看与发布衔接见[架构流程](../../../architecture/flows.md)、[字幕合同](../../../architecture/caption-contract.md)、[运行安全](../../../architecture/runtime-safety.md)和[语义合同](../../../architecture/semantic-contract.md)。

## 1.3. 模块职责与实现合同

Lexicon 拥有可复用词库事实与发布身份；Enrichment 拥有字幕候选、范围映射及提示决策；API 是唯一组合根；扩展只采集、协调并展示。模块经公开合同交互，依赖方向与当前代码定位见[模块边界](../../../architecture/boundaries.md)。离线导入及重建操作见[词库导入指南](../../../development/operations/lexicon-import.md)。

日志/观测字段、原因、打印时机及直接验收要求只在[提示主线观测合同](observability.md)维护。这里不另列代码符号清单、运行配置数值或数据库字段，避免与系统合同和源码的唯一正文漂移。

## 1.4. 验收要求

每个实现工作包应有直接测试；设计工作包须给出可独立核对的合同与合成样例。验收至少覆盖：

- 基础词和词形、完整短语与基础词的区分、可靠低频／无排名词段、低信息短语、非法默认义及同形冲突；
- 查询候选仍为每个起点连续 1～3 个 token，跨片段上下文仅限同视觉行相邻至多 2 段、合计 48 个 UTF-16 单元，提示终点必须在新增范围内；覆盖增量追加与重复、版本切换、冷缓存和发布失败回滚。词库与字幕精确规则分别见[共享词库合同](../../../architecture/lexicon-contract.md)和[字幕合同](../../../architecture/caption-contract.md)。
- 保持原生字幕短暂间隙 650 ms 与请求合并 16 ms 的既有客户端行为；捕获/生命周期安全要求见[扩展运行验收](../../../development/operations/extension-e2e.md)。
- 默认短释的 24 code point 安全上限不裁剪或改写；不安全候选仍参与同形歧义判断，具体规则由[词库导入准备操作合同](../../../development/operations/lexicon-import/record-processing.md)承接。
- 正式／demo 隔离、无资料及依赖故障时的英文降级，授权记录或普通日志故障不改变提示结果；
- 性能计数用于定位和防止明显退化，不据此宣称专项提速；行为变更与行为保持分别提供证据。

合成断言示例：基础词 `the` 及词形为 `BLOCK`；仅有 `allBasicPhrase=true` 的 `take the lead` 不提示；只有与完整 lemma 绑定且来源可信的 `curatedGloss` 可越过完整短语启发式，并仍须通过其他硬校验；可靠低频或无排名词可按质量资格提示，排名未知不伪造为零；正式模式无发布资料不可就绪，显式 demo 必须清楚标识且不能冒充正式资料。具体跨模块验收矩阵见[主线集成验收合同](acceptance.md)。

## 1.5. 冻结与交接

准备阶段只核对规划、文档和策略投影，不声称产品实现验收。派发前依据 Catalog 收紧文件范围；实现、独立验证与审查按 Harness 分离身份，真实观看和发行验收不得由合成测试代替。长期行为合同按本页链接查阅；运行状态、未完成项与实际证据仅见[状态页](status.md)。
