### 1.4.1. 本次真实使用的时延快照

只读采集已安装扩展的页面内存聚合：17 次观察、16 次请求、6 次提示、10 次无可靠提示；超时与晚到均为 0，取消 1 次。原计数不能判断这次取消在哪一段，也不能把无提示全部当成延迟漏译。页面开发日志未返回 LexiFlow 条目；后端分段数据来自实际响应的 Server-Timing，不冒充已取得本次后端原始日志。

| 阶段 | 样本数 | 平均耗时 | p95 |
| --- | --- | --- | --- |
| 采集/摘要 | 17 | 0.51 ms | 1.30 ms |
| 合并等待 | 16 | 156.58 ms | 159.10 ms |
| 传输及扩展消息往返 | 16 | 102.33 ms | 576.50 ms |
| 词库查询 | 13 | 29.03 ms | 46.16 ms |
| 规则 | 13 | 1.00 ms | 4.96 ms |
| API | 13 | 30.19 ms | 47.03 ms |
| 渲染事件 | 65 | 0.18 ms | 0.70 ms |
| 端到端 | 16 | 260.02 ms | 730.10 ms |

固定等待是明显成本；服务端内部查询占主要耗时，传输尾部仍需后续拆查。不同阶段样本数不同，不直接相减均值或百分位。最新代码的本地内置 API 连续夹具端到端均值 34.52 ms、最近 256 样本 p95 46.30 ms；这不是实际视频修复后的测量，不与上述真实使用数据直接作性能收益对比。
