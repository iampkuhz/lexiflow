# 1. 基础体验独立验收

上级：[第一阶段](../foundation.md)；功能边界见[基础体验](experience.md)。下列检查全部通过才可交付，不以文档确认代替实现验收。

## 1.1. 子功能

| 功能 | 必需证据 |
| --- | --- |
| 可靠资料 | 单义可用、完全重复表达归并，不同表达/空项/长文/冲突放弃；无首义截取、无模型依赖；词条、义项和发布版本可核对；引用缺失或无效、同次跨版本结果拒绝。 |
| 规则定位 | 大小写、别名、词形、标点、Unicode、重复词、短语重叠、输入乱序与最大提示数的确定性测试。 |
| API 查询 | 已发布版本查询、无资料、非法输入和后端失败；模块依赖及真实 PostgreSQL 回归。 |
| 字幕生命周期 | 连续换句、跳转、导航、广告、暂停/恢复、字幕关闭；晚到与取消竞态测试。 |
| 展示与偏好 | 英文在摘要及请求前可见、保留来源分行并自然换行、不执行 HTML、绑定范围、可读布局；显式本机抑制与恢复，无网络发送偏好。 |
| 当前页面开关 | 弹窗读取、关闭无请求、立即恢复原生字幕、重开处理当前句、在途结果不可复活、导航重置和旧弹窗操作拒绝；无持久化、跨标签影响或额外权限。 |
| 可观测性 | 各段耗时、计数及失败原因可见且有界；请求前/在途取消、晚到可用结果和服务端计时缺失可区分；无字幕、URL、身份或偏好进入日志/指标。 |

每项保留独立验证命令和原始证据。独立审查只复核冻结 diff 与验证证据，不重跑交付命令或伪造身份。

## 1.2. 端到端

先运行可复现的扩展/API 自动化闭环：包含至少 375 秒实际墙钟的连续合成字幕、各段计时、布局/截图和真实已发布词库的只读抽样。分别标注内置API、已发布词库、renderer mock 与真实网页的证据范围，不相互代替。用户手工把扩展安装到 default profile 后，再在用户指定的真实 YouTube 英文视频检查完整播放。观测提示次数、可靠提示覆盖率、请求成功/无提示/失败/取消分布及分段时延，分母和样本范围必须明确。

至少人工核对十个实际提示（不足十个则全部核对并明确覆盖不足），不得发现误导释义、错句或错范围；无可靠资料的句子允许只有英文。不能通过修改测试、硬编码目标视频词条或截取词典首义制造成功。

在普通播放器及全屏/缩放情况下检查 DOM 和最终截图：英文完整、中文紧随词段、无叠字遮挡、无上一句残留、原生控件可用。截图和字幕仅放本机 ignored 验收产物，不进入 Git 或模型外发。

## 1.3. 完成判定

依次记录子功能结果、自动化 E2E、真实视频质量和截图检查、Change/Repository Verify 与独立正式验收。任何必需检查未执行记 BLOCKED，断言失败记 FAIL。观测覆盖或资料可靠性不足时继续整改，不把“能启动”作为交付。
