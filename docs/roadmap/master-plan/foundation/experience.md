# 1. 基础体验功能与边界

上级：[第一阶段](../foundation.md)。本文定义可独立验收的体验；运行结果只在[状态页](../status.md)维护。

## 1.1. 可靠提示

观看只读已发布词库。第一阶段不实现通用语境消歧：仅接收词条唯一义项的单一、简短中文表达；同一原文范围命中多个不同词条时放弃该范围，不按词典顺序、词频或 UUID 猜词义。

中文表达须为 1–24 个 Unicode 字符、至少包含一个汉字，不含空白、多义分隔符、括号、标记或控制字符。不截断词典文章、不选择列表首项。重复表达归并只在导入预处理中进行：分号分隔的每一项去除可选的短领域标签后，必须逐字相同；发布时保留来源引用，观看时只读取规范表达并执行短表达安全校验，不再次去重。任何一项为空、不同或不合法，整项放弃。多个结构化义项不归并。多个义项、别名/屈折形冲突及无法证明可靠的材料均不展示；这一边界优先于覆盖率。

基础词排除在导入预处理中完成并随词库发布：以来源 Oxford 基础标记与 BNC/FRQ 排名选出前 2000 个独立 lemma，合并固定功能词，持久化提示资格与策略引用；具体规则见[离线词库导入](../../../development/operations/lexicon-import/record-processing.md#12-频率与权重)。词形和别名继承词条资格；含基础词的完整可靠短语不因此被排除。观看时不计算词频阈值、不查黑名单、不合并释义；未完成预处理的资料不提示。真正多候选词义的消歧属于第三阶段。

按原文 UTF-16 范围精确定位，支持大小写、已发布别名和屈折形；不能把单词匹配到另一个单词内部，也不能割断代理对。候选输入顺序不影响结果；优先较长词段，再按原文位置选择不重叠范围，每条字幕最多三个提示，最终按原文位置输出。同一词条在一条字幕中只提示一次。

## 1.2. 字幕与展示

英文原样、即时显示：在观察到字幕的同一轮绘制前，先在稳定的增强层完整绘制英文，再可逆遮蔽原生重复绘制；不等待摘要计算、合并计时或后端。中文就绪后原位补入。保留来源可见分行，同时允许新增中文后的自然换行。中文紧随绑定词段，使用独立文本节点，不拼接 HTML。后端不可用、超时、无可靠资料或响应无效时在同一层仅保留英文；来源失效或关闭增强时立即解除遮蔽。初始化前或无法重建完整英文时保留原生字幕，不承诺所有浏览器环境零首帧闪现。

字幕改变、跳转、广告、导航或页面不可见时，旧请求和旧展示立即失效；晚到结果不得恢复旧字幕。字幕观察身份只用于当前会话失效，不宣称为全局字幕轨道事实。

点击中文提示可显式抑制当前词库版本中的该词条及其词形；播放器的 `LF` 菜单提供恢复全部提示和清空内存统计。偏好仅以稳定词条 ID 与发布版本的组合保存到 `chrome.storage.local`，最多 500 项；新发布版本不会自动继承旧版本的抑制，不存字幕或词段文本，不使用 sync、不上传、不分析熟悉度、不形成观看记录。读取失败不展示中文；保存失败明确提示，不能宣称已保存。

点击浏览器工具栏的 LexiFlow 图标，弹窗只提供“当前页面启用字幕增强”开关。关闭立即取消在途工作、解除遮蔽并停止新请求；开启立即处理当前可见字幕。不影响其他标签页，不保存页面地址或开关历史；刷新或换视频恢复默认开启。导航后拒绝旧弹窗的过期操作，消息/接收端不可用时明确报错，不误称已生效。

## 1.3. 查询与可观测性

API 消费同一发布版本的词库，返回原文、范围、词条/义项/发布版本和确定性状态，不创建待模型处理任务。词条与义项引用必须是规范 UUID；同次结果跨发布版本或引用无效时放弃提示。缓存可删除重建，失败不阻断英文。

每次请求观测采集/身份计算、等待合并、传输、词库查询、规则筛选和渲染耗时；客户端端到端耗时使用同一单调时钟，不直接相减不同进程时钟。聚合只保存阶段、计数、耗时、结果原因，不含字幕、URL、内容身份或偏好值。记录样本数及 p50/p95，区分无提示、失败、超时、取消与晚到丢弃，不以成功请求掩盖失败。取消细分摘要阶段、请求前和在途阶段；`late-ready` 只计已经返回可靠提示但过期丢弃的结果，`stale-at-render` 计最后显示校验的丢弃，不能把所有主动取消都归因于服务太慢。缺少服务端计时另计 `missing-server-timing`，不伪填零。

性能目标不是盲目压低数值；先有可复核基线。请求硬超时 1500 ms，合并等待 16 ms；这些运行边界不能让英文等待，也不能把超时结果显示到下一句。
