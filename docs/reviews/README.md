# 当前评审材料

本目录保存最新评审对象与证据导航，不保存历次运行、失败复盘或复审副本。修改设计后直接更新对应材料；运行收据仍在忽略目录保持不可变，不能用旧哈希证明新正文。

| 材料 | 唯一职责 |
|---|---|
| [G1 决策包](g1-decision-package.md) | 提交用户决定的架构选项及初始数值目标 |
| [架构审查清单](phase-1-checklist.md) | 逐项检查设计，不复制数值目标或执行结果 |
| [用户需求追踪](phase-1-user-requirement-traceability.md) | 用户要求到交付物的对应关系 |
| [任务与证据索引](g1-task-evidence-map.md) | 稳定任务 ID 到当前合同和证明责任的对应关系 |

当前结论只见[阶段状态](../roadmap/phase-1-status.md)，审批操作只见[手册步骤 6](../development/validation/06-phase1-decision.md)。
