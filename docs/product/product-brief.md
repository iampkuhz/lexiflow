# 1. LexiFlow 产品说明

LexiFlow 面向观看英文视频、希望减少整句翻译干扰的用户。它保留英文，只为有语境价值的词、短语和术语提供简短中文提示。产品阶段与共同原则唯一见[产品路线图](../roadmap/master-plan.md)。

## 1.1. 问题与价值

整句双语字幕增加遮挡和阅读切换；词典常见义也不一定符合当前语境。产品选择少量可靠提示，而非用更多中文填满屏幕。没有可靠答案时不提示，不把词库覆盖率等同于语境准确率。

## 1.2. 产品范围

- 首个客户端为 Chrome 扩展，首个来源为有英文字幕的普通 YouTube 点播视频。
- 单词、短语、专业术语三类提示；英文始终是主内容。
- 已发布词库、语义资料与确定性规则支撑观看体验。
- 用户明确选择“不再提示”时，仅在本机保存词段抑制偏好，不上传、不推断熟悉度。
- 事后分析与资料更新遵循第三阶段边界，不影响正在观看的请求。

## 1.3. 非目标

账号、服务端个人档案、自动行为评分、跨设备同步、整句翻译、复习系统、推荐或社交不属于本路线图的已授权能力。其他来源及大规模微服务不提前建设，出现真实需求后先重新对齐产品范围。

## 1.4. 产品证据

需验证字幕取得的稳定性、提示准确性与覆盖、提示密度、出现时机、闪烁、请求耗时，以及本机抑制是否误伤不同语境。验证样本及指标先在阶段设计中确认；不以进程启动、词库命中或历史收据替代体验证据。

各阶段的功能与交付条件见[基础体验](../roadmap/master-plan/foundation.md)、[性能与效率](../roadmap/master-plan/performance.md)、[事后改进](../roadmap/master-plan/improvement.md)；具体进度只在[状态页](../roadmap/master-plan/status.md)维护。
