# LexiFlow

LexiFlow 以英文内容为主，只对有语境价值的词语、短语和术语提供中文提示。首个客户端是 Chrome Extension，首个来源是 YouTube；Lexicon 与 Enrichment 是仅有的业务领域。用户可以显式保存本机词段抑制偏好；产品不提供账号、服务端个人档案或跨设备同步。

产品方向唯一见[三阶段路线图](../docs/roadmap/master-plan.md)，长期合同在 `specs/`。观看只消费已发布资料，不调用模型；第三阶段事后分析可用模型，结果经校验发布供后续观看。当前执行差距与待决事项只在[状态页](../docs/roadmap/master-plan/status.md)维护。
