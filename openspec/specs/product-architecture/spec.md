# 产品架构规范

## 1. 观看链路不使用模型

客户端 MUST 立即显示英文；所有阶段的观看链路 MUST 只消费已发布词库、规则和语义资料，MUST NOT 同步调用模型、为当前字幕创建后台模型补全或进行模型预取。

### 场景：词库或缓存缺失

- 当缺少可靠、适用的已发布资料时，返回不提示，不创建语义补全任务或 pending 承诺。
- 英文继续显示；不得以原始词典截取、多义列表或未经审核结果充当语境答案。已有经审核发布的默认首义时，按默认译法规则提示，不因词条多义而拒绝。

### 场景：已有资料请求晚到

- 资料查询可以异步完成，但返回前和展示前均需关联当前字幕。
- 无保留内容的字幕替换、seek、换轨或导航使旧结果失效；即使文本相同也不得绕过失效。连续追加或前缀退出时，仍完整可见的词段及其有效响应 MUST 保留并映射到新位置。

## 2. 事后分析与发布隔离

第三阶段 MAY 在独立的事后缺失分析中使用模型；模型材料 MUST 经校验、审核和版本发布才能供后续观看消费。观看请求 MUST NOT 发起、等待或订阅该分析，更新不得回补当前字幕。

### 场景：分析失败或未审核

- 模型不可用、分析停止、质量不合格或发布失败时，观看继续使用已发布资料。
- 未审核结果不能进入查询或缓存，发布需要可核对依据并支持回退。
- 路线图不构成新增字幕采集、行为上传、模型外发、个人画像或保留策略的授权。

## 3. 模块化单体与所有权

产品后端使用 Java 25。Lexicon 与 Enrichment 分别是业务 Gradle 项目，各自在 `domain` 和 `application` 包内维护领域规则与应用用例。platform adapters 隔离技术实现，`:api` 是唯一 Spring Boot 运行项目和唯一 `@SpringBootApplication`；HTTP 与未来后台任务由同一应用装配，共四个产品项目，验证和构建工具不计入产品项目。`backend/product/` 与 `backend/verification/` MUST 仅作为物理分类目录，不注册为 Gradle 项目；七个主构建项目 MUST 使用扁平项目路径，`backend/gradle/build-logic/` 保持独立 included build。Domain 不依赖 HTTP、数据库、缓存或供应商 SDK；跨模块只用公开合同，不跨域读写数据。

业务项目 MUST 按功能及职责组织模型、策略、端口与服务，MUST NOT 按 record 语法统一建目录或机械添加 DTO 后缀。Domain MUST NOT 依赖 Application；model MUST NOT 依赖服务、用例或策略实现。持久化同包私有类型 MUST NOT 为目录拆分扩大可见性。Gradle 只声明实际使用的直接依赖，ArchUnit 验证模块内及跨模块边界。

### 场景：规则查询资料

Enrichment 只从 Lexicon 的 `domain.port` 及 `domain.model` 公开合同读取已发布资料，不依赖 Lexicon 的应用层或内置词库实现，以确定性规则判断提示价值及适用性，不为决策调用模型。偏好与提示计数存储 contract 由 Enrichment 公开；`:adapters` 可直接依赖该公开 contract 实现存储，不得直接读写 Lexicon 表。四个产品 Gradle 项目不变。缓存与投影可重建。

## 4. 本机偏好与提示计数

用户明确选择偏好时，扩展通过本机 API 读写独立可写 SQLite；已发布词库 SQLite 保持只读且不可与偏好共库。偏好不得上传、从展示/点击/停留推断熟悉度，或形成服务端个人档案、账号和同步状态。

最近提示 MUST 只计实际呈现词条。本机可写 SQLite MUST 只存日期、稳定词条身份和每日次数，以后端时区保留今天及此前七天；管理端点 MUST 只返回今天及此前六天的合计与已发布词库展示信息。不得持久化单次事件或视频、字幕、播放位置，不得上传或参与提示决策。

当前页面增强开关 MUST 位于工具栏弹窗，不在观看画面增加常驻设置面板。弹窗遵守[上下文规范的弹窗边界](../../../harness/module-boundaries.md#13-工具栏弹窗与管理页)，不读取本机偏好摘要、词表或统计。管理页独占词汇列表、常见词档位、恢复和服务连接编辑。恢复仅撤销个人抑制，不绕过系统规则；本机服务确认保存后才显示成功。连接状态取自当前 API 目标及运行时实际结果。当前视频列表只读打开管理页时绑定的视频会话，在该会话有效时显示来源链接及当页内存中的统计；关闭增强不清除既有词条和次数，也不再累计。切换或离开视频时不保留旧会话，不写入观看历史。当前视频和最近提示均按各自的实际提示次数降序，不能合并计数，缺少发布名次留空。

## 5. 来源与行内展示

Chrome / YouTube 为首个客户端和来源；来源私有类型留在适配器，核心领域只接收有界的标准化字幕上下文。字幕不可靠时不伪造转写、位置或提示。

提示 MUST 以词段区间绑定英文原文，单一简短中文释义插在词段之后。仅同一提示覆盖的多词词组 MUST 以连续黄色底线标出，词间空格属于同一标记，源字幕分行仍保留。单词提示 MUST NOT 画底线；相邻独立提示 MUST NOT 合并成词组标记。显示层仅依据单个合法提示覆盖区间是否包含多个空白分隔词确定标记，不按中文长度、片段 key 数量、撇号或连字符拆词，不改变后端词条选择。词组底线 MUST 位于文本行内并有足够行距，MUST NOT 被下一行字幕背景遮挡；显式分行、自然换行及放大字号均保持可读。来源英文节点 MUST NOT 被改写；完整英文增强层即时就绪后允许可逆抑制重复绘制，不等待中文；保留源分行并允许自然换行。请求失败保留同层英文，来源失效或关闭增强立即解除抑制。仅当前页面开关 MUST NOT 持久化浏览记录或影响其他标签页。经用户明确授权，本机 API MUST 将每个成功处理的新增 `segment.key` 仅记录一次到独立的本机敏感分析日志，包含 JSON 转义的英文、词段提示覆盖与未提示区间；重试和进程重启不得重复计数，未处理或写入失败不得冒充已记录。普通 API logger 和扩展日志 MUST NOT 输出字幕原文或中文提示。经用户明确授权，零参数本机启动器 MUST 自动开启独立的敏感控制台结果流，只镜像成功新写入的片段 JSON；其他启动方式默认关闭，不回放历史、不重复计数，不向普通 logger 转发正文。控制台 MUST 明示敏感性并对换行及控制字符进行 JSON 转义。该记录只表示不可增长的片段 key 已被 API 处理，不表示源字幕消失或用户最终看见提示；不得将它标记为整屏最终渲染。分析日志不得记录观看地址、内容身份、凭据或模型载荷，不得提交、共享或作为指标标签。 客户端实际显示诊断与该台账分开，仅显式启动本机开发诊断时注册；默认及正式运行入口不接收显示事件，不将其写入产品日志。

## 6. 分层规划与交付

产品路线图唯一入口为 [master-plan](../../../docs/roadmap/master-plan.md)，阶段入口约束下级功能设计。方向确认不等于交付验收；未分解的产品阶段不能据路线图自动派发，不复用其他范围的历史收据。执行状态只在[状态页](../../../docs/roadmap/master-plan/phase2/status.md)维护。

### Requirement: 发布前提示资格预处理
仅来源 BNC 的有效正整数原始排名作为公开用户排名，缺失或无效为 null，不与 FRQ 混排，也不把 `priority` 当词频。对有排名且其他条件合格的普通单词，默认 Top 1500 替代 Oxford 固定排除，可选 1000/1500/2000；排名不大于所选档位的单词不提示；缺少 BNC 排名时沿用导入期 Oxford 基础词排除。固定功能词、无效短释、歧义与短语资格规则独立生效；档位只过滤普通单词，在同区间多身份歧义判定之后、重叠裁决之前应用，不修改发布词库。导入仍用 Oxford 证据判定缺少 BNC 排名的单词与独立短语规则；观看不得动态重算基础词名单或归并词典释义。多义词默认义在离线发布期按受核常见义确定与校验；未核词沿来源首候选，不冒称已证明最常见；观看 MUST NOT 截取原始词典列表、现场归并或调用模型排序。UNPROCESSED 资料 MUST NOT 提示。

观看 MUST 排除结构不完整或明显低信息量的短语；按已发布排名证据优先选择非基础词，未排名短语不得只因长度全局占用提示位；完整、可展示且无同区间歧义的已发布短语 MUST 在它完全包含的单词前处理，不改发布 priority 或伪造词频。只为短语到内部单词建立有向包含约束，以既有 priority、长度和稳定 tie-break 排就绪候选，再进行无重叠选择；短语间及非包含的交叉竞争仍使用既有排序，失败短语 MUST NOT 提前删除内部单词。提示必须非重叠，不设置固定三条上限；同区间多词条歧义时不选首条。默认短释 MUST 核对来源表达并随发布政策绑定；完整来源表达、候选顺序依据与来源引用 MUST 在受控资料中保留，不能因只展示首义而删除其他义项。首义是经验默认值，不等于上下文消歧结论或实测概率。

#### Scenario: 消费发布的基础词标记
- GIVEN 词条已在预处理阶段标记为 BASIC_VOCABULARY
- WHEN 当前字幕命中该词条或它的词形/别名
- THEN 不提示该词条，英文继续显示，完整短语独立判断

#### Scenario: 多义词显示默认首义
- GIVEN 一个非基础、符合提示价值规则的词条有多个真实义项，已发布的离线通用默认依据及合法短释
- WHEN 当前字幕准确命中该词条且不存在不同词条身份冲突
- THEN 只展示已受核的通用默认义；未核覆盖处沿来源首候选并如实保留未核状态，不因多义而拒绝，不输出整个多义列表，不调用模型
- AND 完整义项保持可追溯；默认译法不符合具体上下文的风险如实记录，不宣称已消歧

#### Scenario: 多义词缺少可用默认义项
- GIVEN 默认义项未发布、为空、不合法或来源无效
- WHEN 当前字幕命中该词条
- THEN 保留英文，不临时截取来源首项或任取其他义项

## 7. SQLite 持久化与开发期最新结构

仓库 MUST 只维护最新逻辑与架构，废弃接口、配置和数据结构直接替换，不维护历史兼容分支。SQLite MUST 直接更新 `infra/sqlite/schema.sql` 唯一最新结构 SQL；结构变化通过离线事务重建本项目数据库文件并完整重新导入生效，不维护递增迁移链或旧结构适配。API MUST 以只读 `mode=ro` 打开 `/var/lib/lexiflow/lexicon.db`；缺库即拒绝，不隐式创建、初始化或清理数据库。独立本机偏好数据库 `/var/lib/lexiflow/preferences.db` 可由 API 写入，部署显式准备并挂载其持久卷；缺库拒绝，不与词库共库。重建不得影响其他项目数据。

资料的来源绑定、发布标识、完整性验证及受控发布并非旧结构兼容，MUST 保留。重建后不得复用仍被缓存或本机偏好引用的资料身份而绑定不同内容。

### 场景：默认首义的质量边界

观看 MUST 使用离线确定并校验发布的默认义，已证实的通用常见义错排 MUST 在离线资料中纠正。来源 first 不等于 most-common，未覆盖或弱证据词不能宣称已核为全库最高概率；词频排名和词性比例不能冒充义频。完整来源表达与其他义项 MUST 保留，受核候选的来源漂移 MUST 拒绝。观看 MUST 拒绝未经导入校验发布的原始列表截取、未处理资料和无效来源。默认首义可能不适配具体语境；该风险及唯一字面义不适配隐喻等质量缺口不作为默认译法策略的阻塞，也不得宣称已经解决。上下文选择由后续词义消歧工作评估，词库知识缺口由事后资料改进处理；确定性资料校验不等于普遍语境消歧。

## 8. 增量字幕快照

观看请求 MUST 只携带当前可见快照和 `previousSegments`。当前快照按字幕组携带有序 `segments`，片段包含 `key`、`text`、`append`、`line`；`previousSegments` MUST 取当前仍可见且已在上次成功请求中确认的片段，保留原顺序、`key` 和上次发送时的 `text`，供后端验证保留片段只能裁掉前缀；无交集时为 `[]`。主题、轨道、窗口与时间元数据留在扩展；未知时不得伪造。响应 MUST 包含 `processedKeys`、`hints` 和唯一顶层 `lexiconVersion`；未取得资料版本时为 null 且无提示。词段提示含片段坐标、短释、词条身份和可空的 `frequencyRank`，不暴露内部义项身份。

插件 MUST 负责源信息关联、稳定 key、增量识别和展示；key 不因 DOM 重建、换行、短暂空帧或原生 JSON3 时间窗与 DOM 显示短暂错位而改变，新增文字不得增长进旧 key。来源暂时未知 MUST NOT 当作确认换轨，重新确认不同轨道才清除旧身份；未知元数据只在扩展本机记为 null。append MUST 表示本次待处理内容，不是源 aAppend；成功无提示也必须确认处理覆盖。后端 MUST 只因同组内连续新增片段发起查询；仅允许同组、同视觉行且紧邻新增区间的至多两个、合计不超过 48 个 UTF-16 单元的旧尾片段补全词组，提示终点 MUST 落在新增片段；MUST NOT 独立补译旧区间或跨组提示。

新增英文 MUST 立即显示，已有提示 MUST 保留节点；纯换行不发新请求，前缀退出仅移除对应内容。最新视觉行可以接收追加提示；当新行出现、原最新行滚为旧行时，已展示的中文 MUST 冻结，迟到响应不得补写旧行。单请求在途并合并最新观察，失败 MUST NOT 自动重试、确认处理覆盖或推进上次成功快照；仅在失败后的下一次有效字幕变化时，发送最新快照及其与上次成功快照的交集。成功无提示也确认快照；确认 MUST 绑定发送时的冻结快照，而非响应到达时的最新观察；来源隐藏或关闭增强后，迟到结果 MUST NOT 复活字幕。来源私有桥消息视为不可信输入；仅可见文字进入本机 API，字幕和观看身份 MUST NOT 写入扩展日志或持久存储。

CSS roll-up 动画改变可见行但不触发 DOM mutation 时，插件 MUST 在原生字幕动画运行期间逐帧重读可见几何，并在结束或取消时完成末次同步；MUST NOT 使用持续全页轮询或等待网络、timeupdate 才补齐英文。

同一原生裁剪窗口滚动时，插件 MUST 按窗口容量显示最新已进入的完整行，避免部分可见的首尾行同时膨胀成额外整行。连续节点中已退出的旧行 MUST NOT 因 transform 复位而重新出现；仅允许保留仍在 DOM 且正文未变、有可见交集的已展示尾行，不采集未显示的离屏新行。换源、seek、换轨、隐藏或关闭增强 MUST 重置该局部状态。叠加层 MUST 锚定裁剪窗口而非运动中文字的底部。增强行切换 MUST 保留共享行节点，并在仅展示层裁剪离场行、沿原生滚动方向平滑位移；动效结束清理离场行，默认执行滚动动画，不提供关闭动效的分支。 中文短释加入或消失导致行高变化时，动画 MUST 从已绘制位置继续，不得由状态消息或行高重排造成共享行跳变。晚到词释引发换行也只平滑调整仍可见的行，不重开滚动或复活离场行。明确的系统减弱动态效果偏好仍立即切换。 倍速时入场和换行重排 MUST 缩短可读延迟；播放中改速 MUST 保留已绘制位置、延续当前动画。英文仍以原生可见变化为准，不等待查词，也不提前显示尚未进入原生窗口的字幕。

Chrome 扩展的正式与测试构建 MUST 使用各自固定的 Chrome ID；同一标签页只有一套可增强字幕。用户可显式选择本机服务；自动选择 MUST 只探测固定本机端口，并先核对软件、API 与发布资料身份，再允许字幕或本机偏好请求。自定义目标 MUST 为无凭据、无路径的 HTTP 回环地址，所有请求拒绝重定向。扩展本机存储只持有连接配置，不持有字幕、观看历史、偏好或提示计数。初次读取偏好失败时保留英文；后续查词确认服务恢复时 MUST 有界补读偏好，不能要求刷新页面或重发字幕。

## 9. 精简词库持久化与短词条身份

SQLite STRICT MUST 保存七列词条结果、仅非 canonical 两列词形映射和 13 列单行数据集元信息；`imported_at` MUST NOT 保存。`lexicon_lookup` 逻辑视图 MUST 以 `UNION ALL` 重建 canonical lemma 和物理词形的完整查询映射。原始来源字段、逐词处理原因与规则轨迹 MUST NOT 复制入库或改存逐行 JSON。独立单词少于三个字母的形式 MUST 不进入查询窗口；完整短语独立判断。可查询 BLOCK MUST 保留用于同形歧义，不能删除后让有歧义的 HINT 冒出。

词条身份 MUST 是规范 lemma 派生的正 63 位稳定散列，SQLite STRICT 使用 INTEGER，HTTP 和扩展用规范十进制字符串，MUST NOT 转为 JavaScript Number。INTEGER PRIMARY KEY 是 rowid alias，不另有主键 B-tree。碰撞 MUST 拒绝发布并回滚，不随机重分配或合并。义项身份可按发布版本与规范 lemma 确定性派生，无需重复持久化。观看查询候选 MUST 只返回匹配词形、词条与义项身份、资料版本、提示或阻断决定、安全短释、优先级和可空的词频名次。重建 MUST 使用与不同内容不混淆的发布身份；精简结构不授权自动清库。

观看 MUST 一次批量关联词形与词条并保留同形候选。词条使用 `entry_id`、`lemma`、`gloss`、`canonical_form`、`priority`、`bnc_rank` 和 `frequency_rank`；资料包格式为 5，内容摘要绑定两种名次及逻辑映射。用户 Top N 仅使用原始 BNC `bnc_rank`，没有原始名次时保留已发布基础词规则。规范单词若有有效 BNC／FRQ 名次，离线 MUST 按有效最小值升序、并列按规范 lemma 的二进制顺序打破，从 1 连续生成唯一展示名次。没有有效名次的词及短语展示名次为空；变形共享名次。展示名次 MUST NOT 用于选词或预热；`priority` 继续服务 HINT 和预热。原子发布、完整性校验以及失败拒绝保持。


### Requirement: 部署协调与数据生成身份

本机 `install` 与 `upgrade` MUST 使用同一部署编排，将应用构建身份与数据生成身份分别判断。数据生成身份 MUST 覆盖导入、预处理、直接依赖、SQL、影响生成的配置和已校验实际来源摘要；MUST NOT 用应用版本或全仓 commit 替代。只有数据库中的成功记录一致且结构、计数、关联和内容摘要完整时才可复用，其他可读旧结构或不完整资料必须在本次确认后重建并全量导入，不做增量迁移。

普通交互部署 MUST 在数据库连接和重型准备前展示本机目标及按数据导入版本自动替换规则，只进行一次默认拒绝的 `[y/N]` 确认，不询问账密或要求输入 hash。确认仅授权本次调用及展示的目标；内部 MUST 冻结检测后的计划，冻结后的目标或输入漂移 MUST 阻断。显式非交互计划消费 MUST 精确核对当前 hash。SQLite 数据发布 MUST 由离线专用管理命令通过单文件事务完成；初始化、重建、内容校验和成功记录 MUST 原子提交，失败回滚。安装前 MUST 停止 API；目标文件必须是该安装专属路径。发行管理 CLI 使用 `LEXIFLOW_RELEASE_JDBC_URL`，部署数据 CLI 使用 `LEXIFLOW_DEPLOYMENT_JDBC_URL`；请求须绑定绝对目标文件、期望摘要与显式动作，拒绝未知目标、符号链接及漂移。API MUST 以只读方式打开专属数据库文件，不询问数据库账密，不连接外部数据库，不隐式建库、初始化或清库。

数据提交后应用启动失败 MUST NOT 自动恢复可能不兼容的旧应用；恢复 MUST 查询数据库实际提交事实，而非凭本机阶段推测。`up` 不重导，`status`、`logs`、`doctor`、`version` 不恢复或写入安装状态。

### Requirement: 有界受审短语来源

Lexicon MAY 在 StarDict 全量发布事务中准备有限、独立来源的受审短语目录。目录 MUST 明确完整词段、显式词形、中文整理、独立事实、许可及真实核查 actor/依据，并由真实审核证据和精确内容摘要绑定；内容漂移、未审核候选或许可不明 MUST 拒绝发布。工程核查 actor、内容 SHA 锁、法律复用 redistributionApproved 和合同示例 MUST NOT 冒充人类释义确认或不同 actor 的正式验收。仅真实内容审核所绑定的 REVIEWED 子集可正常离线发布，PENDING 或无审核依据的条目 MUST 排除于发布和来源清单。内容 SHA 是完整性锁而非身份认证；独立 AI 内容核查 MUST 记录实际 actor、来源报告和受核输入，不要求用户逐词答复，也不得由自填 CONFIRMED 或 CLI true 绕过。补充来源 MUST 在来源清单按实际许可和摘要独立记录，并纳入 generation identity；MUST NOT 冒称原 CSV 字节、借用 BNC 排名或直接写运行库。普通单词默认义及查询窗口不变，真实字幕 MUST NOT 成为提交的发布资料源。
