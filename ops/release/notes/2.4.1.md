# 1. 2.4.1

## 1.1. 本版变化

- 精简了 macOS Apple Silicon 的 Podman 运行镜像和 Chrome 扩展安装包；词库仍随镜像提供，初始化不需要另下载资料。
- 安装命令指定精确版本。安装或更新只需运行镜像和对应版本的扩展，不必下载第三方源码附件。

## 1.2. 两步使用

前置：macOS Apple Silicon、已安装并运行的 Podman、已安装的 Chrome；本机 18080 端口和 `lexiflow-release` 容器名须空闲。

1. 执行下方安装命令，等待首次初始化完成。
2. 下载同页 Chrome 扩展并解压，在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”。无需配置地址或密码。

## 1.3. 数据与限制

数据保存在 `lexiflow-release-data` 卷，停止或重启容器不会删除。更新前先备份并确认旧卷是否兼容；不兼容时使用新卷，保留旧卷供回退，不会自动迁移旧库。扩展通过开发者模式加载，未上架 Chrome Web Store。
