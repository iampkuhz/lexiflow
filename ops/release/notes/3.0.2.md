# 1. 3.0.2

## 1.1. 本版变化

- 首次建库时意外退出，可用原数据卷重新启动并继续初始化；损坏或不兼容的旧库仍会被拒绝，不会被自动清除。
- 扩展管理页提供词库查询、常见词过滤、停止提示、连接诊断和最近 7 天的提示统计。播放时英文字幕不等待中文提示。

## 1.2. 两步使用

前置：macOS Apple Silicon、已安装并运行的 Podman、已安装的 Chrome；本机 18080 端口和 `lexiflow-release` 容器名须空闲。

1. 执行本页生成的安装命令，等待首次初始化完成。
2. 下载同页 Chrome 扩展并解压，在 `chrome://extensions` 开启开发者模式后加载该目录。

## 1.3. 数据与限制

词库、显式偏好和提示统计留在本机。更新前请保留数据卷；不兼容时使用新卷，不自动迁移或清空旧库。扩展须与服务配套使用。
