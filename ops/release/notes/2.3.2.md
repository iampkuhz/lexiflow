# 1. 2.3.2

## 1.1. 本版变化

- 安装命令明确指定发行版本，便于确认正在安装的包。
- 发行页精简为本版变化、两步使用与数据限制，安装命令和下载入口统一生成。

## 1.2. 两步使用

前置：macOS Apple Silicon、已安装并运行的 Podman、已安装的 Chrome；本机 18080 端口和 `lexiflow-release` 容器名须空闲。

1. 执行下方安装命令，等待首次初始化完成。
2. 下载同页 Chrome 扩展并解压，在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”。无需配置地址或密码。

## 1.3. 数据与限制

数据保存在 `lexiflow-release-data` 卷，停止或重启容器不会删除。已有安装先备份并核对兼容性，不要删除数据卷或直接复用旧版、其他项目的卷；不提供旧库自动迁移。扩展目前通过开发者模式加载，未上架 Chrome Web Store。
