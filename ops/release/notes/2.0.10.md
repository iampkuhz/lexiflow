# 1. 2.0.10

## 1. 使用方式

1. 从 [v2.0.10 GitHub Release](https://github.com/iampkuhz/lexiflow/releases/tag/v2.0.10) 下载 `lexiflow-2.0.10-macos-arm64.tar.gz` 及其 SHA-256 sidecar；该归档约 1.316 GB，包含该代完整离线安装资料。按随包清单和可信 Release 摘要验证后，在固定目录解包。
2. 按该标签的[发行安装说明](https://github.com/iampkuhz/lexiflow/blob/v2.0.10/docs/scenarios/docker-release.md)，先执行 `sh "$RELEASE_DIR/lexiflow.sh" verify`，再依次执行 `prepare`、`activate`、`status`；下载 `lexiflow-extension-2.0.10.zip` 解压，在 Chrome 打开 `chrome://extensions`、启用开发者模式并加载已解压扩展。

## 2. 前置

本版本目标环境为 macOS Apple Silicon、Podman machine 与 Docker 兼容 CLI/Compose plugin；具体要求见上述标签文档。扩展与服务应来自同一 v2.0.10 发行资料。

## 3. 功能与修复

英文字幕优先实时显示；服务使用已发布资料。扩展中的显式词段抑制偏好只保存在本机、不上传；观看路径不调用模型。

## 4. 已知限制

本版本运行 API、PostgreSQL 两个容器，使用完整离线安装归档；Release 资产包含候选、清单和摘要文件。安装需要上述多个命令，不属于单条 `podman run` 启动方式。本文补充使用说明，不改变原标签、附件、镜像或历史验收证据。
