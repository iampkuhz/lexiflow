# 1. 3.0.1

## 1.1. 本版变化

- 扩展管理页分开显示当前视频的词汇提示和近 7 天的提示统计，提供词库查询、常见词过滤、停止提示与连接诊断。
- 扩展和后端使用配套字幕协议。播放时英文字幕不等待中文提示。

## 1.2. 两步使用

前置：macOS Apple Silicon、已安装并运行的 Podman、已安装的 Chrome；本机 18080 端口和 `lexiflow-release` 容器名须空闲。

1. 执行本页生成的安装命令，等待首次初始化完成。
2. 下载同页 Chrome 扩展并解压，在 `chrome://extensions` 开启开发者模式后加载该目录。

## 1.3. 数据与限制

词库、显式偏好与提示统计留在本机；当前视频的统计仅在该页面会话保留。更新前请保留旧数据卷并核对资料结构；不兼容时使用新卷，不自动迁移或清空旧库。扩展通过开发者模式加载，须与服务配套使用。
